# SVME Enterprises — Refined Staffing & Workforce Website

A responsive multi-page frontend for SVME Enterprises using the supplied content and original assets.

## Pages
- `index.html` — Home
- `services.html` — Services
- `employers.html` — Employer enquiry
- `candidates.html` — Candidate registration and jobs
- `contact.html` — Contact and map

## Design direction
- Clean corporate staffing / workforce visual language
- Deep teal, warm cream and muted peach palette
- Strong editorial serif headings paired with DM Sans UI text
- Supplied SVME logo and hero photography retained
- Responsive layouts for desktop, tablet and mobile
- Clear employer / candidate calls to action
- Service selector, industry interaction, slider, forms and application modal retained

## Run
Open `index.html` in a browser or serve the folder with any static web server.

## Production
Forms are frontend demos. Connect them to a backend/API, CRM, email service and secure resume storage before launch.
