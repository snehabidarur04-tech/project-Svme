# SVME Enterprises — Editorial Pastel Frontend

A responsive multi-page frontend redesigned from the supplied visual direction: warm editorial layouts, large serif typography, asymmetric card mosaics, pastel blocks, subtle motion and the original SVME Enterprises logo.

## Pages
- `index.html` — Home
- `services.html` — Services
- `employers.html` — Employer enquiry
- `candidates.html` — Candidate registration and jobs
- `contact.html` — Contact and map

## Visual direction
- Warm cream / blush / sage / lilac palette
- DM Serif Display + DM Sans typography
- Editorial asymmetric grids inspired by the supplied reference
- Scroll reveal, floating cards and button shimmer animations
- Instagram icon with **SVME Enterprises** label
- Original supplied SVME logo used throughout

## Run
Open `index.html` in a browser or serve the folder with any static web server.
